Como gerar o link correto?
SharePoint / OneDrive Empresarial:
1. Abra o arquivo no SharePoint
2. Clique em "Compartilhar" → "Qualquer pessoa com o link"
3. Marque "Permitir edição" = NÃO (só leitura)
4. Copie o link e cole aqui
OneDrive Pessoal:
1. Clique direito no arquivo → "Compartilhar"
2. "Qualquer pessoa com o link pode exibir"
3. Cole o link aqui
Google Drive:
1. Clique direito → "Compartilhar" → "Qualquer pessoa com o link"
2. Cole o link aqui (converte automaticamente)
Se der erro CORS: o SharePoint pode bloquear downloads via navegador.
Nesse caso, use o botão "📂 Selecionar arquivo" — abra o OneDrive local do computador (se sincronizado) e selecione o .xlsx de lá. O mapeamento ficará salvo e na próxima vez basta selecionar o arquivo novamente.
